# WNV_CIU_Fujii

## Overview
This repository contains the original R code used to (A) analyze barcode data generated by PrimerID_BarcodeGenerator_WNVBC_V1.sh and true_barcodes.sh, and (B) generate random mutations. It also includes the original raw data, provided as CSV files, used as input to the code.

# Collective Infectious Units (CIUs) Analysis
Samples are cleaned using background rate (the average barcode counts of a given sequence detected from background sample). Barcode sequences are kept when having a minimum of 2 counts or 2 x rate in the background. Following the rate-based cleanup, barcode sequences that differ by 1 nucleotide from the top sequence of the sample are merged into the top sequence, as they likely represent random mutations during replication. Then for each sample, the number of unique barcode sequence and the prevalence of each sequence are calculated.
